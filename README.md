# МедЖурнал — дневник давления и пульса

PWA-приложение для фиксации измерений артериального давления и пульса. Работает автономно на телефоне (Android/Chrome, iOS/Safari), устанавливается на домашний экран, все данные хранятся только на устройстве.

## Постановка

Одна кнопка — «Записать голосом»: пользователь нажимает и произносит показания
(«Сто двадцать на восемьдесят, пульс семьдесят, подъем по лестнице»).
Приложение распознаёт речь (Web Speech API, ru-RU), извлекает числа, подставляет
их в редактируемые поля проверки вместе с комментарием — пользователь сверяется
с тонометром и сохраняет. Есть полный ручной ввод. История измерений — с оценкой
категории давления. Экспорт всего журнала в CSV. Всё работает офлайн (кроме
самого распознавания речи — оно серверное).

## Возможности

- **Голосовой ввод** (Web Speech API, `webkitSpeechRecognition`):
  - `lang: 'ru-RU'`, `interimResults: false`, до 3 альтернатив — берётся первая, из которой извлекаются показания;
  - парсер понимает цифры (в том числе склеенные в один токен: «122x80-75» → 122, 80, 75) и слова-числительные («сто двадцать пять» → 125); из фразы берутся первые 1–3 числа;
  - порядок всегда фиксированный: первое число SYS, второе DIA, третье пульс, с проверкой диапазонов (SYS 60–260, DIA 30–180, пульс 30–250); значение вне диапазона не заполняется;
  - всё, что произнесено после последнего числа, становится комментарием («подъем по лестнице», «после сна»);
  - ошибки (запрещён микрофон, тишина, нет сети, браузер без поддержки) — понятные сообщения по-русски с кнопкой «Слушать ещё раз».
- **Экран проверки**: SYS/DIA/пульс + комментарий, кнопки «Изменить» / «Сохранить»; валидация диапазонов и SYS > DIA.
- **История**: записи от новых к старым, цветная маркировка категории давления (Оптимальное / Норма / Повышенное / Высокое / Кризисное), удаление по кнопке, счётчик записей.
- **Сводка**: последнее измерение крупными цифрами + категория + пульс + дата.
- **Экспорт CSV**: `medical_diary.csv` (BOM + разделитель `;` — открывается в Excel с кириллицей), хронологический порядок.
- **Offline-first PWA**: service worker кэширует оболочку приложения и CDN-библиотеки; устанавливается на домашний экран (метатеги iOS + manifest с maskable-иконками).

## Структура

```
index.html        — точка входа (Tailwind CDN, Lucide, мета-теги iOS, manifest)
manifest.json     — веб-манифест (standalone, maskable-иконки 192/512 + SVG)
sw.js             — service worker (offline-first)
icons/            — иконки приложения (PNG 192/512 + SVG)
src/app.js        — вся логика: хранилище, рендер, голосовой ввод, парсер, CSV
src/styles.css    — стили (Mobile-First, светлая тема в духе Apple Health)
```

## Технологии

- Ванильный JavaScript, без сборки и зависимостей в коде.
- Tailwind CSS (CDN, версия зафиксирована) + собственные стили.
- Lucide (CDN) для иконок.
- Web Speech API — распознавание речи (серверное в Chrome: нужен интернет).
- localStorage — хранилище измерений (ключ `medjournal.records`).
- Service Worker — кэширование: навигации network-first, свои файлы stale-while-revalidate, CDN cache-first.

## Deployment

Хостится на GitHub Pages (проект в подпапке — все пути относительные, `./src/...`,
`./sw.js`, `start_url: './index.html'`). Требуется HTTPS — на GitHub Pages есть
изначально; камера/микрофон работают только по HTTPS.

## Ограничения

- Распознавание речи требует интернета (серверное в Chrome/Edge); история,
  ручной ввод и экспорт работают офлайн.
- iOS Safari: SpeechRecognition поддерживается с iOS 14.5; в установленном
  PWA может не работать — тогда открывать в Safari (приложение подсказывает).
- Данные хранятся только в localStorage устройства — очистка данных сайта
  удаляет журнал; поэтому есть экспорт в CSV.
